# 2026-10-11 连接故障诊断

本机启动日志显示，机械臂 SDK 无法打开 `/dev/ttyDXL` 后退出，随后控制器因收不到 `get_robot_info` 响应退出；MoveIt 的 IK 和笛卡尔服务仍存在。旧版仅检查这两个服务名，因此误报机械臂就绪。

主机只读检查没有发现 `/dev/ttyDXL`、`ttyUSB*` 或 `ttyACM*` 串口。RealSense D435 已被 USB 枚举，但驱动反复出现 `UVCIOC_CTRL_QUERY` 控制请求超时。内核日志还出现 USB 设备地址枚举失败（`-71`）和 UVC 控制超时（`-110`）。两台设备均通过扩展坞连接；这些证据说明需要排查 USB 链路，尚不能仅凭日志确定是扩展坞、线缆还是供电问题。

排查时先确认机械臂电源，再分别绕过扩展坞接到主机；相机使用 USB 3 数据口。检查 `lsusb -t` 与 `/dev/serial/by-id/`。若仍无任何 USB 串口设备，先排查设备、数据线、端口和供电；若串口已出现但 `/dev/ttyDXL` 缺失，再检查 Interbotix 设备规则。不能通过创建一个无实际设备的串口路径修复连接。

修复后，`/robot status` 验证近期完整关节反馈、驱动响应、活动控制器与轨迹/规划接口；`/camera status` 验证近期有效同步 RGB-D 帧及内参。状态检查不发送机械臂动作。启动失败和中断清理本程序拥有的进程组，避免失败驱动旁边留下规划节点再次误导诊断。

本次主机只读验证返回 `SERIAL_MISSING` 和 `DEVICE_NOT_READY`，与当前设备状态一致。尚未验证重新接线后的真实连接成功，也未执行机械臂运动。
